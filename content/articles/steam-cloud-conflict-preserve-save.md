在新电脑、旧电脑之间切换，或离线模式玩过同一款 Steam 游戏后启动时弹出云存档冲突，适用该游戏商店页带 Steam Cloud 标识、且本机已登录同一账号的情况。处理方向是：先不要继续开玩，也不要在无法同步的提示里硬进游戏；先把本机相关目录复制一份留底，再对照冲突窗口中的修改时间、最后游玩设备和你记得的进度来选。云同步不是多版本备份，选错或覆盖后客服通常无法找回，也不建议强行清空云端或删除 userdata。说明以 [Steam Cloud](https://help.steampowered.com/en/faqs/view/68d2-35ab-09a9-7678) 为准。

## 先停手备份，再看冲突窗口里的时间

Steam 发现本机该游戏相关文件与云端不一致时，会在启动游戏时弹出冲突窗口。同一文件在两处被改过、中间没有完成同步，Steam 无法自动决定保留哪一份。离线模式会阻止同步，重新联网后很容易出现这类窗口。

官方说明云同步是自动进行的，客服处理相关问题的能力有限；若存档或其他数据已经丢失，往往无法恢复。因此窗口出现后应先退出，不要立刻选边开玩。可把本机默认云文件目录复制到其他磁盘或文件夹作为留底，不要在原位置改名或删除。默认路径：Windows 为 C:\Program Files (x86)\Steam\userdata；macOS 为 ~/Library/Application Support/Steam/userdata；Linux 为 ~/.local/share/Steam/userdata。其下先按登录过的 Steam ID 分子文件夹，再按游戏 appID 存放。Steam 客户端设置在同一 Steam ID 下的 7 文件夹。同步活动记在 Steam 安装目录 logs 中的 cloud_log.txt。商店页右上角有 Steam Cloud 标志才表示该作使用云功能，具体哪些文件由开发者自定义，不确定时需向社区或开发者确认。

冲突窗口会列出云端与本地的日期和时间。多数情况应选择最近一次修改的版本，对应你最后一次游玩的进度。但必须把这些时间对照自己的行为：例如昨晚在旧电脑打到某一进度、今早新电脑刚启动就弹窗，就不能只看本机时间戳。

## 按新旧设备和离线游玩分流判断

从旧设备换到新设备却看不到最新进度时，先确认商店页确实使用 Steam Cloud。可能是旧机退出前未成功同步，或同步上去的是更旧的一份。若仍能打开旧设备，应在旧设备联网启动 Steam，让该游戏完成同步后再到新设备启动。许多游戏并不用 Steam Cloud 保存游戏进度，这类文件只能在仍能操作旧机时按开发者指引自行拷贝；旧机已无法使用则无法恢复。Steam 客服可以说明云系统如何工作，但不能恢复丢失存档，也不能代为解决冲突。

若冲突来自离线游玩：离线期间进度只写在本机，联网后才会和云端比对。判断时以离线那台机器、离线时段的进度为准。若弹出无法把本地文件同步到云端的提示，应先处理网络等原因，不要选择继续玩游戏（帮助原文为 play game），否则可能制造冲突并丢掉进度。

可按游戏单独开关云同步：在库中右键游戏，打开属性，在常规页切换 Cloud Synchronization。也可在客户端设置的 Cloud 页面，用 Enable Steam Cloud Sync for applications that support it 对所有支持云的应用统一开关。关闭后，本该上云的进度只会留在当时那台机器本地。开关云同步不能当作备份，官方也未把清空云端或删除 userdata 列为解决冲突的办法。跨操作系统的云数据并非所有游戏都支持，需向社区或开发者确认。

## 同步失败、跨机丢失和常见误操作

持续无法同步时，官方建议在本地信息技术人员协助下排查：重启调制解调器和路由器；无线改为以太网直连试一次；换完全不同的网络（尤其注意可能压缩流量的蜂窝网络）；检查防火墙是否拦截 Steam；杀毒软件是否挂钩磁盘和网络，必要时为 Steam 安装目录和 userdata 加入排除；同时留意广告拦截、网页加速、系统清理、录制、代理、性能加速等后台程序。这些步骤涉及 Steam 以外的系统设置，操作不当可能影响本机，需由专业人员执行。

常见失败：弹窗后立刻选一边并开玩，覆盖了真正较新的进度；换机后没先让旧机同步成功；自行删除 userdata 指望重建；以为客服能从云端翻出被覆盖的版本。替代办法是停手、复制对应 Steam ID 与 appID 目录留底、用冲突窗口时间和自己的游玩记录对照，能开机的旧设备优先完成一次同步。帮助未保证「最近修改时间」一定等于最高游戏进度，也未保证所有游戏都把存档放进 Steam Cloud。
